## 二、竞品 Pro 功能拆解

### AI Product Tools — 最直接的竞品（500+安装，频繁更新）

**免费版：** 无限次使用，用户自备 API Key。
批量生成描述、标题、SEO meta、FAQ、分类描述、图片 alt text — 全部免费。

**Pro 功能：**
- 社区 Prompt 模板库
- 示例内容学习（给一段样例 → AI 模仿风格）
- 聊天机器人界面自定义（主题、配色、图片）
- 高级索引（全描述/SKU/属性/库存量）
- 定时自动索引更新
- 多索引配置
- 生成前自动备份
- 高级筛选（按分类/库存/状态/标签）
- 自定义字段映射
- 内容改进模式（改写/扩写）
- A/B 测试变体

**关键模式：** 免费版已经非常强大，Pro 加的是**锦上添花的效率工具**，不是「解锁被锁的功能」。

### BotWriter — 3,000+安装

**免费版：** 每月只优化 10 个产品（用量限制）
**Pro：** 按月度产品优化数分档：100/500/无限

**关键模式：** 用量限制（不是功能限制），每次优化算一次使用，多个字段也只算一次。

## 四、赛道机会分析

### 【机会 1】深度做「Quick Create」—— 唯一竞品空白

当前市场上 **没有一个插件** 能把「用户给几个关键词 → AI 生成完整 WooCommerce 商品草稿」做深做透。BotWriter 不做、AI Product Tools 不做。我们已经是唯一有 Quick Create 的。

**Pro 机会：** Quick Create 模板库、批量 QC（一次输入关键词生成 10 个产品变体）、CSV 批量 QC

### 【机会 2】「生成前预览 + 编辑 + diff 对比」—— BotWriter 有但做得浅

BotWriter 有回滚功能，但**没有实时预览编辑**。用户生成后经常想微调描述再发布，目前必须：生成 → 去产品页编辑 → 保存。

**Pro 机会：** 内置富文本编辑器直接在生成结果页编辑、修改前后的 diff 高亮、一键回滚

### 【机会 3】「Writing Angle + 品牌语气」垂直做深

我们已经有的 Writing Angle 是竞品没有的差异化功能。但可以更强：
- **品牌语气预设**（存一套 "DraftLab 风格" 设置，每次生成自动应用）
- **历史最佳风格学习**（用户选一个之前比较满意的生成结果 → AI 模仿那个风格）
- 这些功能**100% 靠 API 服务**，不是本地功能，完全符合 serviceware 合规

### 【机会 4】批量 SEO 聚焦

AI Product Tools 的 SEO 功能散在好几个生成器里（title/desc/faq/taxonomy）。**没有一个插件做「一键全站 SEO audit + 批量修复」**。

### 【机会 5】生成历史 + 数据分析

AI Product Tools 的 Dashboard Insights 很初步（只有使用统计）。
**Pro 机会：** 每个产品的生成历史、哪个 prompt 效果最好、哪些产品描述转化率提升——但目前需要 WooCommerce 数据分析集成。

## 五、Pro 功能建议（按优先级）

### P0 — 必须做（审核整改后立即有卖点）

| 功能 | 为什么是 Pro | 工作量 | 合规性 |
|------|:-----------:|:------:|:------:|
| **批量 Quick Create**（一次生成多个产品变体） | ✅ 服务端 API 调用次数增加 | 低（现有 QC 加循环） | ✅ Serviceware |
| **编辑-预览-发布工作流**（生成结果页内嵌富文本编辑器） | ✅ 需要本地存储/回滚数据 | 中（React + REST） | ⚠️ 本地功能 → 必须放独立 Pro 插件 |

### P1 — 高价值差异化

| 功能 | 为什么是 Pro | 工作量 |
|------|:-----------:|:------:|
| **品牌语气预设**（存多套语气/角度配置） | ✅ Serviceware | 低 |
| **定时自动生成**（cron 驱动批量更新） | ✅ Serviceware | 中 |
| **生成历史 + 回滚**（可视化 diff，按产品/时间筛选） | ✅ 本地存储 → Pro 插件 | 中 |
| **CSV 导入/导出**（关键词列表批量 QC） | ✅ 本地处理 → Pro 插件 | 低 |

### P2 — 长期壁垒

| 功能 | 说明 |
|------|------|
| **AI 图片生成**（DALL-E/Stable Diffusion 自动配产品图） | API 服务，完全合规 |
| **多语言自动翻译**（一键翻译已有描述到 10+ 语言） | API 服务 |
| **AI 关键词生成器**（写一段产品描述 → AI 提取 SEO 关键词） | API 服务 |

## 六、最终架构建议

```
WP.org 免费版               Pro 插件（独立，Freemius）
─────────────────────       ──────────────────────
单商品生成                   保留免费版全部功能
Quick Create（基础）         批量 Quick Create
批量生成（不再锁）            品牌语气预设
Pexels 配图                  定时批量生成
自定义 Prompt                生成历史 + diff 回滚
Apply All                    CSV 批量导入
                             AI 图片生成
                             【未来加】
```

**核心逻辑：** WP.org 版是**功能完整可用的工具**。Pro 插件是**效率提升 + 额外 AI 服务**。
所有本地功能（历史、回滚、富文本编辑）放在独立 Pro 插件里，不在 WP.org 代码中出现。
